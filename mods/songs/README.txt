If you don't remember how to make mods, go back to the first README.txt.

Edit the JSON file by putting your chart, your song name, and your username.

IMPORTANT:
JSON does not support comments.

Do not put // comments inside your MySong.json file,
because NEON RHYTHM will not be able to read it.

If you want to write notes about your chart,
keep them in a separate text file.
