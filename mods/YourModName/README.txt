========================================
       NEON RHYTHM MOD TEMPLATE
========================================

Welcome to NEON RHYTHM!

This template helps you create your
own NEON RHYTHM mods.

No Python programming is required.
You mainly need to edit JSON files.

----------------------------------------
FOLDER STRUCTURE
----------------------------------------

ExampleMod/
├── mod.json
├── README.txt
└── songs/
    └── MySong.json

----------------------------------------
INSTALLING YOUR MOD
----------------------------------------

1. Copy the ExampleMod folder.

2. Rename it to whatever you want.

3. Put it inside:

   NEON RHYTHM/mods/

4. Start NEON RHYTHM.

Your mod should automatically appear
in the game!

----------------------------------------
MAKING A SONG
----------------------------------------

Songs go inside:

songs/

Each song is a .json file.

Example:

MySong.json

----------------------------------------
CHARTING NOTES
----------------------------------------

Notes use:

[BEAT, LANE]

Lane numbers:

0 = LEFT
1 = DOWN
2 = UP
3 = RIGHT

Example:

[4, 0]

means:

Beat 4 → LEFT

[4.5, 1]

means:

Beat 4.5 → DOWN

Have fun making your charts!
