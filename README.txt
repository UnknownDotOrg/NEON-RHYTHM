========================================
           NEON RHYTHM
========================================

Hi! Thanks for downloading NEON RHYTHM!

NEON RHYTHM is a rhythm game made
entirely in Python using Pygame.

----------------------------------------
HOW TO PLAY
----------------------------------------

To play the game, open a terminal
window in the NEON RHYTHM folder.

Then type:

python3 PythonRhythm.py

----------------------------------------
PYTHON
----------------------------------------

If you don't have Python installed,
you can download it here:

Windows:
https://www.python.org/downloads/windows/

macOS:
https://www.python.org/downloads/macos/

Linux:
Python is normally already installed
on most Linux distributions.

----------------------------------------
REQUIREMENTS
----------------------------------------

Python 3
Pygame

----------------------------------------
MODS
----------------------------------------

NEON RHYTHM supports mods!

Put your mods inside the game's:

mods/

folder.

For information about making your
own mods, see the included mod template.

========================================
        Have fun playing!
